# Store Procedures

## Buscar nombre alternativo (Convertidor)

```sql
SELECT EXTERNAL_NAME
FROM INFORMATION_SCHEMA.ROUTINES
WHERE ROUTINE_NAME='PX172S02A1838';
```

## Buscar Store Procedure

```sql
SELECT ROUTINE_NAME,SPECIFIC_NAME,EXTERNAL_NAME
FROM QSYS2.SYSPROCS
WHERE ROUTINE_SCHEMA='PRAXIS'
AND SPECIFIC_NAME='PX172S02A1838';
```

## Buscar parámetros de un SP

```sql
SELECT SPECIFIC_SCHEMA,SPECIFIC_NAME,ORDINAL_POSITION,
PARAMETER_MODE,PARAMETER_NAME,DATA_TYPE,
CHARACTER_MAXIMUM_LENGTH
FROM QSYS2.SYSPARMS
WHERE SPECIFIC_SCHEMA='PRAXIS'
AND SPECIFIC_NAME='SQP05424'
ORDER BY ORDINAL_POSITION;
```

## Dar permisos

```sql
GRANT ALL ON PROCEDURE PRAXISMP.SQP05716 TO PUBLIC;
```

# Tablas

## Buscar tabla física

```sql
SELECT TABLE_SCHEMA,TABLE_NAME,SYSTEM_TABLE_NAME
FROM QSYS2.SYSTABLES
WHERE TABLE_SCHEMA='PRAXIS'
AND TABLE_NAME='A2462';
```

## Buscar columnas

```sql
SELECT COLUMN_NAME,DATA_TYPE,LENGTH
FROM QSYS2.SYSCOLUMNS
WHERE TABLE_SCHEMA='PRAXIS'
AND TABLE_NAME='A2462';
```

## Buscar tablas

```sql
SELECT TABLE_NAME
FROM QSYS2.SYSTABLES
WHERE TABLE_SCHEMA='PRAXIS'
AND TABLE_NAME LIKE '%A246%';
```

## Buscar vistas

```sql
SELECT *
FROM QSYS2.SYSVIEWS
WHERE TABLE_SCHEMA='PRAXIS';
```

## Valores distintos

```sql
SELECT DISTINCT TPAX
FROM PRAXIS.A4622
ORDER BY TPAX;
```
